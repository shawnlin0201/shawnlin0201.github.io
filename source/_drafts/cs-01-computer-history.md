# 電腦發展

## 真空管電腦時期

第一章節一開始介紹了計算機的定義與由來，從算盤（abacus）開始講解，直到了 Jacquard loom 的出現開始有打孔卡片運作機械的工具出現，後來 Herman Hollerith 將其應用於計算工具上發展了 Tabulating Machine 協助美國於兩年半完成人口普查（原先需耗時七年半），後來也成立了對應的組織 Tabulating Machine Company 也就是 IBM 的前身，觀察與思考這一路的發展其實也相當有趣，科學總是在不統領域上交會出新的火花，筆者我自己也相信更好的理論總是出現在兩種合併分析之後。

而在 1937 年 Alan Turing 提出圖靈機的概念，透過無窮多格的磁帶來記錄內容，每個空格中可能為空或是有內容，而透過定義狀態來使其向左向右，修改或塗銷等行為來使其產生邏輯進而達到可以記錄等等功能，中間又陸續歷經了像是 HP 公司的成立與出現所謂的 ABC 電腦，解決了一些基礎的數學方程式問題。

直到 1944 年受 IBM 贊助的哈佛大學完成了史上第一台透過電來驅動的機械計算機叫做 Mark I，那時候的電腦算得上一種巨型怪獸，以現代的小坪數住宅來說可能光擺上 Mark I 就已經差不多塞不下其他家具了，而且功能可能還不如當時的其他小型計算器。

後續 John Louis von Neumann 提出儲存程式的概念（stored program）影響到後續數位化時代的電腦都使透過這個概念來構成，查了一下資料簡單來說原先打卡孔設備可能得要按照一定的「規則」才能夠執行，比方讀取當下格子如果沒有就⋯⋯有則⋯⋯，然後透過設定狀態來區別不同的行為等等，而儲存程式概念主要暗示的是儲存裝置與判斷的處理器可以將其分開之外，判斷的處理器則應當可以藉由設定所謂的指令，然後將其轉化成執行細節，而資料輸入後就可以取得計算完的結果。

其設計核心在於『儲存程式』的概念以及四個子系統：

- 記憶體（Memory）
- 運算邏輯單元（Arithmetic Logic）
- 控制單元（Control Unit）：控制記憶體與運算邏輯的運作。
- 輸入/輸出（Input/Output）：負責將資料與程式碼輸入至計算機中，例如鍵盤；以及將結果從計算機中輸出至設備（螢幕等）或是儲存裝置。

而運算邏輯單元與控制單元合併起來還可稱作中央處理器（Central Processing Unit, CPU）

題外話，越好改的東西伴隨著副作用的部分則是錯誤的發生也越容易，所以沒有妥當錯誤處理的話也會造成機器損壞等等問題發生。

接著便是於 1946 年賓州大學 Mauchly Eckert Jr. 所製作出著名的真空管計算機 ENIAC，透過真空管所製作出來這台真空管計算機書中提及比前面 Mark I 快上千倍，但體積仍然也不算小，查了一下圖片確實也仍是可以塞滿小房間的那種等級，仍然沒辦法普及到各個家庭內，但作為時常提案與研究的我來說，探索性的研究通常就是先求有再求好的過程，所以對當時來說這種發明仍然是非常重要的。

再到 1952 年，知名的資訊學家 Grace Murray Hopper 設計出了第一個編譯器（將目標語言轉換成電腦可讀懂 0 1 陣列），並且設計出了 COBOL 程式語言與參與制定規則，為後續程式語言發展帶來相當大的影響與啟發。其中有一段故事蠻有趣的是 Hopper 為了向當時的一些聽眾解釋 nanosecond 到底是什麼於是剪了一段電線向觀眾表示這就是一個電子在 nanosecond 能跑的距離，這也是暗示了未來電子計算機將取代機械計算機的開端。

## 電晶體電腦時期
1956 年 Shockley, Bardeen & Brattain 發現了電晶體效應後，1959 年 Honeywell 公司開發出電晶體計算機，使計算機體積耗電與散熱得到很大一部分的改良，並於 1963 年美國國家標準局制定了所謂的 ASCII 編碼標準，其中 II 並不是二的意思全名為 American Standard Code for Information Interchange。

## 積體電路電腦時期
1964 年資訊界的巨擘 IBM 推出了以積體電路為主要設計基底的計算機，效能與體積又比起電晶體電腦好了更多，而較為具體的呈現則是對應到 I/O 的數量，原先真空管一根只能用來處理一件事情，但是小小的積體電路 I/O 數量是真空管的好幾倍，在這樣的優勢下使得計算機可以推廣至更多的場所當中，不過此時與現代 2000 年後的電腦相比仍然是怪獸，只是體積可能剩下兩台大冰箱的程度。

## 超大型積體電路電腦時期
由於積體電路在各方面帶來極大的好處，所以人類不斷在這領域上發展，直到 1971 年 Intel 的處理器已經可以容納數千數萬的電子元件。而電子元件從大約一根手指的真空管到比頭髮還小的超大型積體電路，也就意味著計算機的體積越來越小、成本越低，而到 1975 年 Altair 推出第一個個人用的電腦，也象徵著電腦已普及到家庭中使用。

# 電腦網路與程式語言

在 1989 年 Tim Berners-Lee 提出了 WWW（World Wide Web）的概念，最初只是讓物理學家們能夠方便交換圖文文件，但隨著時間發展影響到不只是學術領域的部分。

1994 年前端熟悉的好朋友 Netscape 瀏覽器推出，結果 Windows 採用隨機（器）附贈的策略使得 IE 瀏覽器使用率大勝 Netscape；此外，在當時搜尋網站這件事情得要拿著一本簿子輸入對應的網址才能找到特定的站台，因此 Yahoo 適時推出了搜尋引擎能讓大家藉由這個服務找到其他的站台，因此也讓 Yahoo 爆紅，並在 2000 年併購奇摩變成 Yahoo 奇摩。

而 1995 年 James Gosling 率領團隊推出了 Java 語言，既說原本要叫做 Oak 但商標已經被註冊了才改名叫做 JAVA（如果是這樣的話那前端用的語言差點變成了 OakScript）

一直來到 1998 年，Google 搜尋引擎推出，藉由更快更好的服務逐漸撼動 Yahoo 的地位。

2001 年除了 Window XP（XP，原意取用 eXPerience，意圖表示這版著重在人的體驗上），另外就是推出了維基百科的站台，甚至還有研究論文比較了大英百科全書與維基百科的差別，由於發表在知名期刊上，還鬧起了不小的風波。
